# 理财从零开始

面向理财新手的中文学习网站。课程按照“先管好钱 → 认识工具 → 学基金 → 读股票与财报 → 建立组合 → 学会使用软件”的顺序组织，用短课、图解和练习帮助读者从概念走向独立查证。

**在线学习：**[打开网站](https://lc.royi.net/)  
**项目仓库：**[K-zhaochao/Financial_freedom_PRO](https://github.com/K-zhaochao/Financial_freedom_PRO)

## 课程内容

目前共有 **6 个阶段、31 节课**：

| 阶段 | 学习重点 |
| --- | --- |
| 01 先管好钱 | 目标、现金流、应急金、债务与风险 |
| 02 认识投资工具 | 收益来源、风险、证券与常见投资品种 |
| 03 基金入门 | 指数基金、费用、定投与基金选择 |
| 04 股票与财报 | 企业、估值、财务报表与研究问题 |
| 05 组合与心态 | 资产配置、纪律与长期执行 |
| 06 软件实战 | 行情、盘口、分时图、K 线，以及同花顺、东方财富、TradingView、淘股吧的使用与术语 |

每课包含核心概念、例子、动手练习和参考书籍。软件课程另配教学重绘的盘面示意图与官方操作资料链接。图中的数据为虚构示例，不代表真实行情或软件截图。

## 建议学习方法

1. 按阶段顺序阅读，先完成现金流与风险基础，再接触具体产品。
2. 每课先看图解，再读正文，用自己的话完成课后练习。
3. 根据页面列出的书籍和章节回到原书核对；涉及软件功能时，以对应官方帮助页面和当前版本为准。
4. 学习进度保存在当前浏览器的本地存储中，不需要注册账户。

## 本地运行

网站是静态页面，无需安装依赖。在项目根目录运行：

```bash
python -m http.server 4173 --directory dist
```

然后访问 [http://localhost:4173](http://localhost:4173)。

## 项目结构

```text
dist/
├── index.html             页面结构
├── portal.css             主站样式
├── software.css           软件实战图解样式
├── content.js             前五阶段课程与书籍信息
├── software-content.js    软件实战课程
├── visuals.js             基础课程图解
├── software-visuals.js    盘面与软件示意图
├── site.js                课程导航、阅读与进度
└── images/                课程配图
.openai/hosting.json       静态站点部署配置
```

修改课程内容后，可直接刷新本地页面预览。部署时应发布 `dist/` 中的静态文件。

## 内容来源与边界

课程以项目整理的理财、基金、财报、股票和投资心理书籍为主要参考，按照初学者的学习路径重新编写；每课在页面末尾标明相关书籍及章节。软件功能说明参考同花顺、东方财富、TradingView 和淘股吧的官方页面。软件界面和规则会更新，遇到差异请以最新官方信息为准。

仓库只放网站代码与自行制作的图解，**不收录参考书籍的 PDF 或原文全文**。课程用于学习，不构成针对个人情况的投资建议。
