# 理财从零开始

面向理财新手的中文学习网站。课程按照“先管好钱 → 认识投资工具 → 学基金 → 读股票与财报 → 建立组合 → 学会使用软件”的顺序组织，用长课、图解、算例和练习帮助读者从概念走向独立查证。

**在线学习：**[打开网站](https://lc.royi.net/)  
**项目仓库：**[K-zhaochao/Financial_freedom_PRO](https://github.com/K-zhaochao/Financial_freedom_PRO)

## 课程内容

目前共有 **6 个阶段、46 节课**，正文合计约 21.9 万字（每课平均约 4,750 字，最短约 3,500 字）。每课含 5～7 个知识小节、2～3 段深入讲解、3～4 组常见误区对照、一个带数字的算例、案例拆解、关键数字卡、术语卡、要点小结和 2～3 道练习，并在末尾给出参考章节与「回原书怎么读」的导读。

| 阶段 | 课程数 | 学习重点 |
| --- | --- | --- |
| 01 先管好钱 | 6 | 目标与期限、现金流与结余、应急金、债务与还款顺序、复利、通胀与购买力 |
| 02 认识投资工具 | 5 | 股票 / 债券 / 基金的权利差异、风险的多重含义、债券与利率、市场周期、费用与规则 |
| 03 基金入门 | 6 | 指数编制与跟踪、基金分类、指数估值（盈利收益率法与博格公式）、定投与年化收益、挑基金清单、定投计划 |
| 04 股票与财报 | 9 | 商业模式与竞争优势、三张报表、ROE 与财务比率、读年报、财务疑点与价值陷阱、估值与安全边际、分红与股东回报 |
| 05 组合与心态 | 7 | 资产配置、分散与相关性、再平衡、回撤应对、市场情绪、认知偏差清单、投资规则卡 |
| 06 软件实战 | 13 | 行情字段、盘口、分时与 K 线、同花顺 / 东方财富 / TradingView / 淘股吧、条件筛选、完整研究流程、术语速查 |

每课末尾列出所依据的书目与章节，并附“回原书怎么读”的逐节导读。软件课程另配教学重绘的盘面示意图与官方操作资料链接；图中的数据为虚构示例，不代表真实行情或软件截图。

## 建议学习方法

1. 按阶段顺序阅读，先完成现金流与风险基础，再接触具体产品。
2. 每课先看图解，再读正文；算例自己动手算一遍，误区对照用来检查自己原来的理解。
3. 用右侧目录的搜索框按关键词（如“回撤”“ROE”“定投”）跳转；每课末尾列出书籍与章节，可以直接点顶部「参考书架 · 在线阅读」翻原书核对。
4. 学习进度保存在当前浏览器的本地存储中，不需要注册账户。

## 本地运行

网站是静态页面，无需安装依赖。在项目根目录运行：

```bash
python -m http.server 4173 --directory dist
```

然后访问 [http://localhost:4173](http://localhost:4173)。

## 项目结构

```text
dist/
├── index.html             页面结构
├── portal.css             主站样式（含课程新版块与阅读器）
├── software.css           软件实战图解样式
├── github.css             GitHub 按钮样式
├── content.js             前五阶段课程、阶段与书目信息
├── software-content.js    软件实战课程
├── books-index.js         参考书 PDF 清单（由 sync-books 生成）
├── visuals.js             基础课程图解与阶段插图
├── software-visuals.js    盘面与软件示意图
├── site.js                课程导航、搜索、书架与在线阅读
├── books/                 参考书 PDF（17 册，见 BOOKS-NOTICE.md）
└── images/                课程配图
.openai/hosting.json       静态站点部署配置
BOOKS-NOTICE.md            PDF 收录声明、侵权联系与撤下方式
```

课程内容集中在两个 `*-content.js` 文件中，每课是一个对象：`lead` 导语、`points` 知识小节、`deep` 深入讲解、`pitfalls` 误区对照、`example` 算例、`case` 案例、`numbers` 关键数字、`terms` 术语卡、`takeaways` 要点、`task` 与 `exercises` 练习、`sources` 与 `readings` 参考与导读。修改后直接刷新页面即可预览；部署时发布 `dist/` 中的静态文件。

## 参考书架与在线阅读

顶部「参考书架 · 在线阅读」按钮会列出 17 册书，每册提供「在线阅读」入口，点击后在站内全屏阅读（浏览器自带 PDF 阅读器），也可以在新窗口打开。手机浏览器对内嵌 PDF 支持不一致，建议用新窗口或下载后阅读。

书目清单由 `dist/books-index.js` 提供，字段为 `key / file / size / label`；`bookNotice` 提供版权提示文案、Issues 地址与联系邮箱（填上邮箱后网站会自动显示）。撤下任意或全部 PDF 后，书架上对应条目会显示「未收录电子版」，课程内容不受影响。

## 内容来源与边界

课程以项目整理的 17 册理财、基金、财报、股票与投资心理书籍为研究底本，按照初学者的学习路径重新编写；书中的方法、历史数据与章节位置均经过原文核对，页面标注时期与口径。软件功能说明参考同花顺、东方财富、TradingView 和淘股吧的官方页面。

`dist/books/` 中的 PDF 著作权归原作者与出版方所有，**仅供个人学习研究使用，不得用于商业用途或二次分发**；如有侵权，请联系删除，详见 [BOOKS-NOTICE.md](BOOKS-NOTICE.md)。课程用于学习，不构成针对个人情况的投资建议；涉及费率、税率、交易规则时，请以官方最新规定为准。
